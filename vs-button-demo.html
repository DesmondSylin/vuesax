VsButton 獨立 CSS/JS 範例

無需 Vue.js，純 HTML + CSS + JS 即可使用的按鈕元件

1. 基本按鈕類型

Filled（填滿）

<button class="vs-button vs-button-filled vs-button-primary">Primary</button>

Border（邊框）

<button class="vs-button vs-button-border vs-button-primary">Primary</button>

Flat（扁平）

<button class="vs-button vs-button-flat vs-button-primary">Primary</button>

Line（線條）

<button class="vs-button vs-button-line vs-button-primary">Primary</button>

Gradient（漸層）

<button class="vs-button vs-button-gradient vs-button-primary">Primary</button>

Relief（浮雕）

<button class="vs-button vs-button-relief vs-button-primary">Primary</button>

2. 尺寸變化

<button class="vs-button vs-button-filled vs-button-primary vs-button-large">Large</button>

3. 帶圖示的按鈕

<button class="vs-button vs-button-filled vs-button-primary">

</button>

圓形圖示按鈕

8. 自訂顏色

提示：您可以通過修改 CSS 變數來自訂顏色主題
:root {
--vs-primary: 25, 91, 255;
--vs-success: 70, 201, 58;
--vs-danger: 242, 19, 93;
--vs-warning: 255, 186, 0;
--vs-dark: 36, 33, 69;
--vs-light: 240, 240, 240;
}

9. JavaScript API

自動初始化

引入 vs-button.js 後，所有帶有 .vs-button class 的按鈕會自動初始化 ripple 效果。

手動控制載入狀態

// 設定載入狀態
VsButton.setLoading('#manualLoadingBtn', true);

// 取消載入狀態
VsButton.setLoading('#manualLoadingBtn', false);

10. 安裝與使用

引入檔案

<!-- Material Icons（可選，如需使用圖示） -->
<link href="https://fonts.googleapis.com/icon?family=Material+Icons" rel="stylesheet">

<!-- VsButton CSS（必需） -->
<link rel="stylesheet" href="vs-button.css">

<!-- VsButton JS（可選，用於 ripple 效果） -->
<script src="vs-button.js"></script>

基本使用

<button class="vs-button vs-button-filled vs-button-primary">
我的按鈕
</button>
注意：
  • CSS 檔案是必需的
  • JS 檔案是可選的，用於增強 ripple 效果
  • Material Icons 僅在使用圖示時需要
