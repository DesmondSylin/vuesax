Vuesax Theme CSS3 使用範例

這是從 Vuesax Vue.js 組件庫提取的主題色彩系統，使用現代 CSS3 自定義屬性（CSS Variables）實現。

CSS 自定義屬性（變量）

所有顏色都以 RGB 格式存儲，支持透明度調整：

--vs-primary: 31, 116, 255
--vs-secondary: 121, 49, 177
--vs-danger: 255, 71, 87
--vs-success: 70, 201, 58
--vs-warning: 255, 186, 0
--vs-dark: 30, 30, 30
--vs-light: 245, 245, 245

使用方式：

/* 使用完整不透明色 */
color: rgb(var(--vs-primary));
background-color: rgb(var(--vs-success));

/* 使用帶透明度的顏色 */
background-color: rgba(var(--vs-primary), 0.1);
border-color: rgba(var(--vs-danger), 0.5);

整合指南

1. 引入樣式表

<link rel="stylesheet" href="style.css">

2. 使用工具類別

<!-- 按鈕 -->
<button class="vs-button vs-button-primary">點擊我</button>

<!-- 提示框 -->
<div class="vs-alert vs-alert-success">成功訊息</div>

<!-- 背景色 -->
<div class="vs-bg-primary">主要背景色</div>

<!-- 文字色 -->
<p class="vs-text-danger">危險文字</p>

3. 使用 CSS 變量

.my-custom-element {
  /* 使用完整顏色 */
  background-color: rgb(var(--vs-primary));

  /* 使用帶透明度的顏色 */
  border: 2px solid rgba(var(--vs-success), 0.5);

  /* 使用其他主題變量 */
  border-radius: var(--vs-border-radius);
  transition: var(--vs-transition);
  box-shadow: var(--vs-box-shadow);
}

4. 自定義主題顏色

您可以在自己的 CSS 中覆蓋這些變量：

:root {
  /* 自定義主要顏色為紫色 */
  --vs-primary: 138, 43, 226;

  /* 自定義成功顏色為青色 */
  --vs-success: 0, 188, 212;
}
